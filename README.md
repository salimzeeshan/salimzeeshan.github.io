# Mohammad Zeeshan Salim Portfolio

A personal portfolio built to present my frontend engineering experience, project work, and contact details in a focused, recruiter-friendly format.

The site is designed as a polished single-page experience with smooth navigation, responsive layouts, dark mode, project media, and concise career storytelling for interviewers, hiring managers, and collaborators.

## Live Site

[salimzeeshan.github.io](salimzeeshan.github.io)

## Highlights

- Built with Next.js App Router, React, TypeScript, and Tailwind CSS.
- Responsive portfolio sections for hero, about, skills, experience, projects, education, and contact.
- Smooth section navigation with active link tracking and scroll progress.
- Dark and light theme support with persistent theme preference.
- Project showcase with video previews, posters, live links, and GitHub links.
- SEO metadata, Open Graph preview, Twitter card metadata, and profile-based favicon.

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **UI:** React, Tailwind CSS
- **Animation:** Framer Motion
- **3D / Visuals:** Three.js, React Three Fiber
- **Deployment:** Vercel

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

## Project Structure

```text
app/                 Next.js app routes and global layout
components/          Reusable portfolio sections and UI components
data/                Profile, experience, education, skills, and project data
hooks/               Scroll, section tracking, and cursor hooks
lib/                 Shared utilities
public/              Profile image, Open Graph asset, and project media
types/               Shared TypeScript types
```
